# איקס עיגול · זירת הקרח

A Hebrew, right-to-left tic-tac-toe game with an ice-rink look. Play against the computer or another person on the same board.

## How to play

Open `index.html` in a browser. No build step or server is required.

- **נגד מחשב** — you play as ○; the computer plays as ✕ with a minimax AI.
- **שני שחקנים** — take turns as ○ and ✕ on the same device.
- **מהלך אחורה** — undo the last move (in AI mode this also undoes the computer’s reply).
- **סיבוב חדש** — start a new round; scores stay until you switch game mode.

## Project files

| File | Role |
| --- | --- |
| `index.html` | Page layout, board, scoreboard, and controls |
| `styles.css` | Ice-rink theme and animations |
| `game.js` | Turns, scoring, undo, and AI |
